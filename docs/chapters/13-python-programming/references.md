# References: Programming the Station in Python

1. [Python (programming language)](https://en.wikipedia.org/wiki/Python_%28programming_language%29) - Wikipedia - Describes Python's history, design ideas, and why it is popular for science and teaching. Its examples of readable syntax and its huge library collection explain why this book uses Python for the station.

2. [Control flow](https://en.wikipedia.org/wiki/Control_flow) - Wikipedia - Explains how programs make choices and repeat steps using conditional statements and loops. Side-by-side examples in several languages help students see the same if, for, and while ideas used in this chapter.

3. [Exception handling (programming)](https://en.wikipedia.org/wiki/Exception_handling_%28programming%29) - Wikipedia - Describes how programs catch and recover from errors instead of crashing. It gives background for the chapter's try and except code, which keeps the station running when a sensor fails to respond.

4. Automate the Boring Stuff with Python - Al Sweigart - No Starch Press - Sweigart pioneered teaching Python through practical, everyday tasks like renaming files and reading spreadsheets instead of abstract puzzles. His approach suits students writing a real program to read and record sensor data.

5. Think Python - Allen B. Downey - O'Reilly Media - Downey ends each chapter with a debugging section and a glossary, teaching students to think like programmers who expect and fix mistakes. This habit pairs well with the chapter's focus on exception handling.

6. [Errors and Exceptions](https://docs.python.org/3/tutorial/errors.html) - Python Documentation - The official Python tutorial chapter on syntax errors, exceptions, and try, except, and finally blocks. Short code examples show exactly how to catch a failed sensor reading and keep a program running.

7. [Beginner's Guide to Python](https://wiki.python.org/moin/BeginnersGuide) - Python Software Foundation - The Python community's starting page for new programmers, with links to installation help, tutorials, and learning resources. Teachers can use it to find extra practice suited to different student levels.

8. [Programming with Python](https://swcarpentry.github.io/python-novice-inflammation/) - Software Carpentry - A free lesson for beginners that teaches variables, loops, conditionals, functions, and error handling using a real scientific dataset. Its exercises mirror how scientists analyze measurements like those from the station.

9. [CS50's Introduction to Programming with Python](https://cs50.harvard.edu/python/) - Harvard University - A free online course with video lectures, notes, and problem sets on functions, conditionals, loops, exceptions, and libraries. Motivated students can go well beyond this chapter at their own pace.

10. [CircuitPython Libraries on Linux and Raspberry Pi](https://learn.adafruit.com/circuitpython-on-raspberrypi-linux) - Adafruit Learning System - Shows how to install the Blinka library so Adafruit's sensor libraries run on a Raspberry Pi. It demonstrates how a Python library turns a complex sensor into a few lines of code.
